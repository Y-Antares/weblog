Auto link title 【debug】

Q：使用中发现知乎的文章链接粘贴过来总是识别不出：[Title Unavailable \| Site Unreachable]。

A：

  • auto link title 解析微信公众号标题失败？ - 疑问解答 - Obsidian 中文论坛 [4]

    • 对于网页内部的链接，可使用浏览器插件CopyCat拷贝猫- Chrome 应用商店Chrome Web Storehttps://chromewebstore.google.com › … [5]解决，但它有2个缺点，所以我不使用：
      • 不能应用于当前页面的链接
      • 生成的标题很长，效果差

  • Fetch Zhihu link title · Issue #122 · zolrath/obsidian-auto-link-title · GitHub [6]

    • 本质是知乎加强了反爬虫政策，所以需要我们自定义域名cookie。使用feat: Add support for specifing domain request headers by Mlk1225 · Pull Request #158 · zolrath/obsidian-auto-link-title · GitHub [7]这一PR可以解决。
      • 拉取PR并替换插件文件的方法可见于：
      • 替换好插件后，在Auto Link Title插件设置中配置。
      • Cookie获取方式：打开浏览器登录知乎，F12 打开开发者工具。“网络”中找到一个请求，在 Request Headers 里复制Cookie。
