“insecure download blocked”【已阻止不安全的下载】

Chrome 下载文件时总是提示“已阻止不安全的下载”的解决方案 - 知乎 [1]

我允许了从QQ空间下载照片：https://user.qzone.qq.com。It works!

" This extension may soon no longer be supported"【这些扩展程序可能很快将不再受支持】

This extension may soon no longer be supported because it doesn’t follow best practices for Chrome extensions.

该提示出现在我安装的【简悦SimpRead】插件上。其github issue可很好地解决问题：如果你的浏览器提示【这些扩展程序可能很快将不再受支持】的解决方案 · Kenshin/simpread · Discussion #6633 · GitHub [2]。对于windows用户来说，关闭Chrome并CMD运行"C:\Program Files\Google\Chrome\Application\chrome.exe" --disable-features=ExtensionManifestV2Unsupported,ExtensionManifestV2Disabled即可。

出现在谷歌学术LABS页面上。

解决方法：关闭chrome浏览器和google scholar页面后，切换VPN节点，并清除cookies。
