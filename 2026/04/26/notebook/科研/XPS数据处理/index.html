    Advantage基础处理

    参考：

    • XPS原始数据处理Avantage及其绘图Origin全过程（因为自己处理完表征数据过了不到一个月又… [1]

    • 利用Avantage和Origin软件处理XPS数据( 校正、拟合、绘图、配色)_哔哩哔哩_bi… [2]

    下载advantage：百度网盘 请输入提取码 [3]

    1 打开文件

    • .VGD是原始数据。

      • 其中XPS Survey.VGD是全谱，覆盖较宽的结合能范围；
      • C1s Scan.VGD等是窄谱，只测一个峰附近的较小能区，用更高能量分辨率、更多采样点，专门看该元素的化学态和峰形。

    • .vgp是工程文件。包括分析步骤与结果。

    建议从File-Open打开.VGD，直接拖入Advantage会闪退。

    可能出现版本不兼容提示，但一般不用管：

    2 电荷矫正

    以C1s进行电荷矫正。

    首先最大化C1s图谱，右键选择Show XPS Knowledge for this spectrum，找到C-C标准结合能（284.8 eV），我们将用它进行电荷矫正。也可以访问XPS 元素表 | 赛默飞 | Thermo Fisher Scientific - CN [4]查询。

    然后回到图谱，可用Select Peak功能初步观察自己的峰位置。

    2.1 添加基线

    先以C1s添加基线（扣背底）：Peak Add：Add -> Close 注意，这同时也会增加一个单峰。

    2.2 拟合

    加适量峰后（如3个），对C1s进行峰形拟合。图中红线是原始数据，蓝线是拟合数据，橙线是峰。

    Peak Fitting：

    • Add Fitted Peak -> Add Single Peak 刚才已经加了一个峰，现在点一次就是两个峰

    • Fit Peaks -> Fit This... -> Ok 得到C1s Scan A

    2.3 电荷矫正

    全选当前峰（图的左上角），进行电荷矫正：Charge Shift -> 勾选Allow shifts of non-integral chan... -> 输入与284.8最近的峰与其差值（e.g. 下图中应+0.18eV） -> Accept & Close

    如果希望每次自动勾选allow shifts，可在首选项中设置：

    3 分峰

    s峰为单峰，p/d/f峰为双峰。

    例：Pt4f

    选中Pt4f的窄谱，直接点击Peak Fitting进行分峰。

    XPS Peak41 分峰

    参考教程：XPS——x射线光电子能谱分峰拟合-经验分享-读懂XPS结合能表-第一期_哔哩哔哩_bilibili [5]

    下载：XPS分峰软件XPSpeak41-生命科学与化学学院 [6]

    1. 导入经过电荷矫正的txt数据：`Import ASCII

    2. 设置背底：主要调整High BE和Low BE，Type=Shirly、Slope=0一般不调整。两个BE不可离峰过近。

    1. 分峰拟合：逐个Add Peak

    • 确定3/2对应的1/2之依据：E(2p12)−E(2p32)=17.3eVE(2p\frac{1}{2})-E(2p\frac{3}{2})=17.3eVE(2p21​)−E(2p23​)=17.3eV

    • 卫星峰：X射线靶所致，也要拟合

    1. 导出数据：Export(Spectrum)

    例：Ni2p

    以Ni2p为例演示一遍：

    1. 按顺序加：Ni0 双峰 + Ni2+ 双峰 + 2 个 Sat.

    注：FWHM味半峰宽；= 需要勾选constrained

    # Peak Position FWHM Area
    Ni0 3/2 Peak 0 852.8, fix
    Ni0 1/2 Peak 1 = Peak 0 + 17.3 = Peak 0 = Peak 0 / 2
    Ni2 3/2 Peak 2 855.45, fix
    Ni2 1/2 Peak 3 = Peak 2 + 17.3 = Peak 2
    		 = Peak 2 / 2
    Sat. Peak 4 861.0
    Sat. Peak 5 880

    PS：个人认为应该在加卫星峰前optimize一次，以保证主峰强度高于卫星峰。
    PPS：视频评论说“在XPSpeak里面Lorentzian-Gaussian比值最好固定在20% 比较好。Lorentzian成分反映谱峰固有属性，而Gaussian成分反映仪器自身特性。一般测量里谱仪特性占大头，所以主要以高斯型来拟合更合理。我一开始也是不固定，后来发现固定20%反而结果拟合会更贴切，分享下。”

    1. 全部Accept后，Optimize All。蓝线是原始数据，黑粗线是拟合数据。

    2. 为提升拟合效果，可逐渐放开约束：

      • 放开Peak2、Peak0的fix
      • 放开Peak1、Peak3 FWHM与Peak0、Peak2的相似（原则上应该相似），自己调整后fix
        • （我认为这一步不要放开为好）
      • 放开Peak1、Peak3 L/G的fix
