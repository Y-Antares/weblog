下载并安装

版本选择

一般肯定是建议选择最新版本的，所以这里给的是2023版。旧版出现的问题及解决可见文末。
更新：不要下载2024版，网上给的license不管用。用2023版就行，功能上没有太大差距。

安装教程见： https://www.bilibili.com/video/BV1T5afenErD/?share_source=copy_web&vd_source=8a438cffea857af16bb7e16993b22ffe

下载链接： https://pan.baidu.com/s/1xcnrtXBgggTUFD-jMmKCaA?pwd=0000

  4. 若已安装仍不能运行，右击修复

卸载

参考

Materials Studio卸载分享_哔哩哔哩_bilibili [2]

  1. 先打开MS所在文件夹（C盘BIOVIA那个），删除

  2. 在控制面板卸载MS相关的软件和服务

  3. 删除当初下载的安装包(setup)和许可证(crack)

一定要彻底卸载，再安装下一版MS。

旧版问题

1. 下载盗版

网上随便找找就有。

  • 8.0版本可参考此教程 [3]
    链接: https://pan.baidu.com/s/1kzW-j4-E3ThAj-tBUbhGjQ 提取码: nurp

  • 19.02版本可见此网站 [4]的百度网盘
    链接: https://pan.baidu.com/s/1gFTV-wP-6rnZvkja04ClKg 提取码: ir83

网上查了一下，据说两个版本的建模差不多，在计算效率和精度方面有差异。本着精益求精的态度，顺便测评两个版本的强度。

安装时注意要手动install license，并记得将msi.lic的this host或HR替换为本机用户名。

2. 项目创建或迁移

8.0 版本

弹出来提示框，问：

网上的解决 [5]往往是旧版本的，用到的魔术棒我没在本版本找到。干脆全部勾选Claim。

create project时的路径必须是英文，否则报错：
An error occurred while creating the new project: Failed to reset diagnostics manager.BSTR could not be converted to narrow CP_ACP string without use of surrogate pairs, in BSTRToString()

打开学校机房运行到一半的项目时，报错：
This project was generated with a more recent version of Materials Studio and cannot be opened with the current version of Materials Studio.
直接把原项目所有文件复制到新建的项目里。

然后在打开xsd文件时报错：

哈哈，那怎么办呢。根据论坛回答 [6]，记事本打开模型文件，更改第三行的版本为当前版本。（19.1->8.0）
重新打开，好像没什么问题。

19.02版本

和8.0版本比，少了版本报错。看来19.02和19.1是互通的。

3. 运行项目

19.02 版本

计算时报错：

参考论坛 [7]进行修复安装，成功解决。

虽然core数的最大值由12提升到了20，但计算速度比机房电脑慢。看来台式还是有台式的无敌。
这quench简直要运行到地老天荒了。和台式机上一样，progress卡在78运行不动了。网上找不到解决方案，怀疑是运算量太大，电脑算力不够导致的。

后来发现确实只是运行需要的时间太长导致的。
